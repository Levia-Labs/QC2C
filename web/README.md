## Files

1. `world_sectors.json` is the manifest with plain sector keys, so it works over static hosting with no `Content-Encoding`.
2. Each plain sector file holds the polygons of one sector.
3. The gzip copies keep `.gz` keys in their manifest, for hosts that serve `Content-Encoding: gzip`.
4. `qc2c.json` is deterministic metadata: package version, code and point counts, file sizes, settings, validation summary and input hashes.
5. `preview.png` is a world render of the build with sector boxes.

## Use on the website

The Levia Labs website copies this folder into its static assets at build time. Then:

```ts
import { coordinatesToCountry } from "qc2c";

await coordinatesToCountry({ lat: 52.23, lng: 21.01 }, { manifest: "<base>/world_sectors.json", sectors: "<base>" });
```

## Use the hosted data

The website serves this folder at `https://www.levialabs.net/assets/qc2c/`. These snippets work only after the website ships `web/`.

TypeScript or Node:

```ts
import { coordinatesToCountry } from "qc2c";

const code = await coordinatesToCountry(
  { lat: 52.23, lng: 21.01 },
  { manifest: "https://www.levialabs.net/assets/qc2c/world_sectors.json", sectors: "https://www.levialabs.net/assets/qc2c" },
);
```

Python, standard library only:

```python
import json
from urllib.request import urlopen

from qc2c import get_country, get_sector

BASE = "https://www.levialabs.net/assets/qc2c"
point = {"lat": 52.23, "lng": 21.01}


def fetch(name):
    with urlopen(f"{BASE}/{name}") as response:
        return json.load(response)


sector_key = get_sector(fetch("world_sectors.json"), point)
code = get_country(fetch(sector_key), point) if sector_key else None
```

Browser use from another domain needs the host to send CORS headers; until then, copy `web/` into your own site.
